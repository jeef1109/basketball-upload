# 文件像投篮球 · Basketball Upload

把上传文件变成一次轻松的投篮。

**[在线体验](https://jeef1109.github.io/basketball-upload/)** · 手机和电脑均可访问

## 玩法

- 拖动小文件，松手投篮；也可用 Enter 或空格试投。
- 点击 **Drop files here** 选择真实文件，或从电脑拖入文件。
- 文件每次出现在随机位置；进球后随机换色，文件和篮筐颜色同步。
- 点击扬声器开启轻快循环音乐、出手破风声与入网得分音。
- 顶部切换 **简约 / 复古拼贴**，浏览器会记住风格选择。
- 点击 **Uploaded** 查看、下载或删除已保存文件。

## 文件存储

文件通过 IndexedDB 保存在当前设备的浏览器中，不会上传到 GitHub 或其他服务器。单文件上限 100 MB。浏览器存储不可用时，只保留到当前页面会话结束。清理浏览器数据会移除已保存文件。

试投使用应用生成的演示文本文件。

## 本地运行

可直接打开 `index.html`，或启动静态网页服务：

```sh
python3 -m http.server 5180
```

浏览器访问 `http://localhost:5180`。

使用 Node.js 时：

```sh
npm install
npm run dev
npm run build
```

构建输出位于 `dist/`。网站使用原生 HTML、CSS、JavaScript 和 Web Audio API，无后端。
